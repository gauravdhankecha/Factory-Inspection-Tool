# ફેક્ટરી ઇન્સ્પેક્શન ટૂલ — Next.js

Claude માં બનેલું "ફેક્ટરી ઇન્સ્પેક્શન ટૂલ" હવે પોતાની વેબસાઇટ તરીકે: લૉગિન, પોતાનો ડેટાબેઝ (Postgres) અને Vercel પર deploy.
બધી ટેબ — નવું ઇન્સ્પેક્શન, પડતર, દફતર, બંધ કેસ, માસિક ડાયરી, સારાંશ, ઇન્સ્પેક્શન સમરી, વાર્ષિક રીમાઇન્ડર — અને Word/Excel ડાઉનલોડ પહેલાં જેવા જ છે.

## ત્રણ પ્રકારના ખાતા

| ભૂમિકા | કોના માટે | શું કરી શકે |
|---|---|---|
| અધિકારી (એડમિન) | તમે | બધું + કેસ કાઢી નાખવા + વપરાશકર્તા/બેકઅપ પેજ |
| ક્લાર્ક (ડેટા એન્ટ્રી) | ક્લાર્ક | નવું ઇન્સ્પેક્શન, ફેરફાર, ડાયરી, PDF અપલોડ — કાઢી નહીં શકે |
| સાહેબ (ફક્ત જોવું) | સાહેબ | બધો ડેટા જોવો અને Word/Excel ડાઉનલોડ — કોઈ ફેરફાર નહીં |

પરવાનગી સર્વર પર ચકાસાય છે, એટલે બટન દબાવે તો પણ સાહેબના ખાતાથી ડેટા બદલાતો નથી. "વપરાશકર્તા / બેકઅપ" પેજમાં કોણે ક્યારે શું બદલ્યું તેની યાદી પણ દેખાય છે.

## ૧. Vercel પર ચાલુ કરવું (ભલામણ)

1. આ ફોલ્ડર GitHub પર એક **private** repository માં મૂકો (`data/` ફોલ્ડર જાતે બહાર રહેશે — તેમાં તમારો સાચો ડેટા છે).
2. [vercel.com](https://vercel.com) → **Add New → Project** → એ repository પસંદ કરો → Deploy.
3. Project → **Storage → Create Database → Neon (Postgres)** → project સાથે connect કરો. તેનાથી `DATABASE_URL` આપોઆપ ઉમેરાશે.
4. Project → **Settings → Environment Variables** માં ઉમેરો:
   - `AUTH_SECRET` — ૩૨+ અક્ષરનું રેન્ડમ લખાણ. બનાવવા: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
   - `ANTHROPIC_API_KEY` — (વૈકલ્પિક) "ફોટા પરથી ફોર્મ ભરો" માટે. [console.anthropic.com](https://console.anthropic.com) પરથી મળે.
5. **Deployments → Redeploy**.
6. સાઇટ ખોલો → પહેલી વાર **સેટઅપ** પેજ આવશે → તમારું (અધિકારી) ખાતું બનાવો.
7. **વપરાશકર્તા / બેકઅપ** પેજ:
   - "બેકઅપ / જૂનો ડેટા ઇમ્પોર્ટ કરો" → આ ફોલ્ડરની `data/inspection-backup.json` પસંદ કરો — Claude ટૂલના બધા ૬૯ ઇન્સ્પેક્શન, ૯૧ ડાયરી એન્ટ્રી અને સેટિંગ્સ આવી જશે.
   - સાહેબ માટે "સાહેબ (ફક્ત જોવું)" અને ક્લાર્ક માટે "ક્લાર્ક (ડેટા એન્ટ્રી)" ખાતું બનાવો, અને યુઝરનેમ/પાસવર્ડ તેમને આપો.

## ૨. પોતાના કમ્પ્યુટર પર ચલાવવું

જરૂરી: [Node.js 20 કે નવું](https://nodejs.org) અને એક Postgres ડેટાબેઝ (સૌથી સહેલું: [neon.tech](https://neon.tech) પર મફત ડેટાબેઝ બનાવી તેનું connection string લો).

```bash
cd inspection-tool
copy .env.example .env.local     # Mac/Linux: cp .env.example .env.local
# .env.local ખોલીને DATABASE_URL અને AUTH_SECRET ભરો
npm install
npm run dev
```

પછી બ્રાઉઝરમાં http://localhost:3000 ખોલો.

## ધ્યાનમાં રાખવાની બાબતો

- **જવાબ PDF** ૪ MB સુધીની અપલોડ થાય છે (Vercel ની મર્યાદા). મોટી હોય તો compress કરીને મૂકો.
- **ફોટા પરથી ફોર્મ** માટે `ANTHROPIC_API_KEY` જરૂરી છે; ફોટા બ્રાઉઝરમાં જ નાના કરીને મોકલાય છે. મોડલ બદલવું હોય તો `ANTHROPIC_MODEL` સેટ કરો.
- **બેકઅપ**: "વપરાશકર્તા / બેકઅપ" → "બેકઅપ ડાઉનલોડ કરો" — અઠવાડિયે એક વાર લઈ રાખો.
- બે જણ એક જ કેસ એક સાથે બદલે તો છેલ્લે સેવ થયેલું રહે છે.
- કોઈ ખાતું બંધ કરો કે ભૂમિકા બદલો તો તે તરત લાગુ પડે છે.
